# Progressive Learning Framework

将工具拆分为可消化层级的教学结构。

## The Five Levels

### Level 1: Overview & Motivation

**Goal**：理解 WHAT 和 WHY

Cover：

- 这个工具解决什么问题？
- 之前存在什么？为什么这个更好？
- 谁在使用它？用于什么场景？
- 什么时候不应该使用它？

### Level 2: Installation & Hello World

**Goal**：在本地运行起来

Cover：

- 前置条件
- 安装步骤
- 最小可运行示例
- 运行它，查看输出
- 验证是否正常工作

### Level 3: Core Concepts

**Goal**：理解心智模型

Cover：

- 3-5 个核心概念
- 它们之间如何关联
- 每个概念一个示例
- 每个概念常见的错误

### Level 4: Practical Patterns

**Goal**：构建真实可用的东西

- 覆盖最常见的使用场景
- 提供代码示例帮助上手，循序渐进地从简单示例开始，逐步增加细节。例如，如果工具是一个 agent SDK：
  - 首先展示如何构建一个非常简单的 agent
  - 然后展示如何连接 tools
  - 再展示如何创建带有 subagents 的 workflow

### Level 5: Next Steps

**Goal**：知道如何深入学习

Cover：

- 可探索的高级主题
- 每个主题的最佳资源
- 社区资源
- 如何获取帮助
- 提出一个小型项目或动手练习

## Code Example Principles

- 每个示例必须完整且可运行
- 从最小示例开始，逐步增加复杂度
- 展示预期输出
- 对非显而易见的部分添加注释
- 展示常见错误及修复方法
